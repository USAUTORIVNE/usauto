# Картинки сайту

Кладіть файли сюди, а потім вписуйте шлях у `src/lib/media.ts`.

| Слот у `media.ts` | Де на сайті | Рекомендований розмір |
|---|---|---|
| `logo` | Логотип у шапці та футері | 240×64, PNG/SVG |
| `hero` | Головне фото авто в першому блоці | 1200×1500 (вертикальне), JPG |
| `heroSecondary` | Квадратне фото-вставка поверх головного | 600×600, JPG |

Приклад:

```ts
hero: {
  src: "/assets/hero.jpg",
  alt: "Ford Mustang після доставки",
  hint: "1200×1500 · JPG",
},
```

Картинки для варіантів квізу (типи кузова, паливо) додаються в
`src/lib/quiz-config.ts` через поле `image`, напр. `image: "/assets/body-sedan.png"`.
Поки картинки немає — показується вбудована іконка.
